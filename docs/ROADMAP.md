# Roadmap

## Delivered and reported

- The November 15 documented public lifecycle is recorded in the [WO18 closeout](../examples/local-chain/WO18_PUBLIC_CLOSEOUT_20261115.md): nine canonical Pudge transactions, including creation, funding, delegate payments, revocation, closure and late-deposit recovery.
- A subsequent November 20 real-wallet lifecycle was reported in the [Nervos Talk progress report](https://talk.nervos.org/t/quotacell-let-your-team-spend-without-handing-over-the-treasury/11002/23). It describes delegate payments, permission changes and closure. That first-party report is separate from the repository's detailed November 15 canonical audit record.
- Independent acceptance beyond these first-party records, and independent security qualification, remain outstanding.

## Next priorities

1. Headless delegate execution using existing QCN4.
2. Native policy rejection and executor reliability qualification.
3. Independent recovery and fragmented-fund handling.
4. Metatype feasibility investigation.
5. Authentication and multi-wallet feasibility.
6. A reusable integration boundary based on actual consumers.
7. Independent security review before mainnet consideration.

These are investigation and qualification priorities, not commitments to replace the current architecture. Mainnet readiness is not claimed.
