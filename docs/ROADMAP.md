# Roadmap

This is a status-oriented roadmap. Items below are outstanding unless labeled verified; no planned item should be read as a delivered capability.

## Verified baseline

- Native QCN4/QCT4 policy and a nine-transaction public Pudge lifecycle; see `examples/local-chain/WO18_PUBLIC_CLOSEOUT_20261115.md`.
- Browser Pocket discovery, draft collaboration and local transaction supervisor components exist; see `PROJECT_HANDOFF.md` for qualification boundaries.

## Outstanding

- Complete owner-authorized creation and hosted wallet-action acceptance with independent discovery and canonical inclusion evidence.
- Improve cross-device Pocket recovery without relying on local descriptors.
- Qualify conflict handling, reorganization behavior, recovery, and multi-fund consolidation.
- Conduct independent security review before any real-value use.
- Explore headless delegated payment using the existing policy and signing boundary; agent integration is not implemented.
- Multiple wallet profiles, mainnet deployment and production readiness require separate design, qualification and review.
